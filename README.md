\# APEPE Community Flow



A community-driven opinion collection and result announcement system for the APEPE project.



\## Overview



This module lets the community share opinions on upcoming directions and displays the final results once decisions are made.



\## Pages



\- \*\*index.html\*\* — Landing page introducing the community flow

\- \*\*form.html\*\* — Opinion submission form (connected to Supabase)

\- \*\*result.html\*\* — Result announcement page



\## Tech Stack



\- HTML / CSS / JavaScript

\- Supabase (data storage)



\## Status



Active development.
